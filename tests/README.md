# Test experiments

Experiments tagged **Test** live here, one folder each. A Test experiment
examines one thing in depth; a **Benchmark** compares models and lives in
`../benchmarks/`.

Nothing here yet. Copy `../_template/` to start one.

Note the name collision, because it will catch you: this directory holds
*experiments*. The `tests/` directory **inside** an experiment folder holds that
experiment's Python test suite. Different things, same word.
